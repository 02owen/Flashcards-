القواعد الرئيسية ونهايات الأسماء (من كتابك)

Le / Un علامات الاسم المذكر (Masculin)

  • • **أيام الأسبوع والأشهر والفصول وأسماء اللغات والأشجار:** مذكر دائماً (مثل: l'été, le français, le pommier).
  • • النهايات الشهيرة للمذكر: -ment, -eau, -age, -isme, -ail.
  • • الأسماء المنتهية بـ **S / X** في المفرد تبقى كما هي عند الجمع وتكون مذكر بشكل عام: (le pays, le fils, le jus, le temps, le prix).

La / Une علامات الاسم المؤنث (Féminin)

  • • النهايات الأكثر شهرة للتأنيث:
  • -tion / -sion / -xion -tte / -lle / -sse / -nne -ée (عامة) -ère / -euse / -ice -aison / -ise -té / -ude / -ade -ance / -ence -ure / -rie

القاعدة العادية الاستثناءات (عكس القاعدة!) التوضيح
الكلمات المنتهية بـ -age تكون مذكر la page / la plage / la cage / la nage / la rage / la image هذه الكلمات **مؤنث** رغم انتهائها بـ -age!
الكلمات المنتهية بـ -eau تكون مذكر la peau / l'eau الجلد والماء **مؤنث** رغم انتهائهما بـ -eau!
الكلمات المنتهية بـ -ée تكون مؤنث le musée / le lycée المتحف والمدرسة الثانوية **مذكر**!
الكلمات المنتهية بـ -té تكون مؤنث l'été / le côté / le comité الصيف والجانب واللجنة **مذكر**!
الكلمات المنتهية بـ -ence تكون مؤنث le silence الصمت **مذكر**!
الكلمات المنتهية بـ -ade تكون مؤنث le stade الاستاد/الملعب **مذكر**!
الكلمات المنتهية بـ -ère تكون مؤنث le père / le frère / le ministère / le mystère الأب والأخ والوزارة والسر **مذكر**!
الكلمات المنتهية بـ -sse تكون مؤنث le pamplemousse الليمون الهندي **مذكر**!
